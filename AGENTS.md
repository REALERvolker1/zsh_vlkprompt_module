# Code style

Rust `no-std`, This is a FFI-based plugin.

**IMPORTANT:** Before allocating _anything_, read `./docs/params.md` to learn how zsh memory works.

ZSH FFI bindings are exported via the `zsh-sys` crate, more specifically in the very large autogenerated file
`./vendored/zsh-sys/src/bindings.rs`.

ZSH macro-like APIs and various helper functions are in `./vendored/zsh-sys/src/macros`

You may read `./gitignored/zsh/Src/Modules/example.c` or any other `.c` files located
in that directory to learn how zsh modules work.

# FORBIDDEN

- **DO NOT HIDE/LEAK ALLOCATION INSIDE OF FUNCTIONS**
- **DO NOT ABUSE HEAP-ALLOCATED TYPES** (Ex. Hiding unrelated data inside of hash tables, doing weird shit with linkedlists, etc.)

# Testing

use `test.sh` to verify functionality.
